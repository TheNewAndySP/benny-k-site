# Benny K — Site

## Como publicar no GitHub Pages

### 1. Criar o repositório
1. Acesse https://github.com e faça login
2. Clique em **New repository** (botão verde)
3. Dê um nome: `benny-k-site` (sem espaços)
4. Deixe como **Public**
5. Clique em **Create repository**

### 2. Fazer upload dos arquivos
1. Na página do repositório, clique em **uploading an existing file**
2. Arraste a pasta `github-pages/` (ou os arquivos dentro dela) para a área de upload
3. Clique em **Commit changes**

### 3. Ativar o GitHub Pages
1. Vá em **Settings** (aba no topo do repositório)
2. No menu lateral, clique em **Pages**
3. Em **Branch**, selecione `main` e a pasta `/ (root)`
4. Clique em **Save**

### 4. Acessar o site
Aguarde 1-2 minutos. O site estará disponível em:
```
https://SEU_USUARIO.github.io/benny-k-site/
```

## Sobre as imagens
As fotos arrastadas nos slots (hero, coleções, lookbook, etc.) ficam salvas no navegador (localStorage). Para que apareçam para todos os visitantes, arraste as fotos diretamente no site publicado — elas ficam salvas permanentemente naquele navegador/dispositivo.

Para uma solução definitiva com imagens fixas, entre em contato com o desenvolvedor.
